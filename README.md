# Pracci Pro — Official Artist Website

A modern, responsive music website for **Pracci Pro**, the Zambian hip hop artist from Kafue.

## Features

- **Hero** – Strong branding and call-to-action
- **About** – Artist bio and project list
- **Music** – Spotify embed + links to Spotify, Audiomack, Apple Music, YouTube
- **Videos** – Embedded official music videos from YouTube
- **Connect** – Social links (Instagram, X, YouTube, Linktree, etc.)
- Fully responsive (mobile-friendly)
- Dark hip-hop aesthetic
- Static site — perfect for **GitHub Pages**

## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `pracci-pro` or `username.github.io`).
2. Upload all files in this folder (`index.html`, `styles.css`, `script.js`, `README.md`) to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Source**, select **Deploy from a branch**.
5. Choose the `main` (or `master`) branch and `/ (root)`.
6. Click **Save**.

Your site will be live at:
- `https://username.github.io/repo-name/`  
  or  
- `https://username.github.io/` (if the repo is named `username.github.io`)

## Custom domain (optional)

In the same Pages settings you can add a custom domain (e.g. `praccipro.com`).

## Local preview

Just open `index.html` in a browser, or run a simple local server:

```bash
# Python
python -m http.server 8000

# Node
npx serve
```

Then visit `http://localhost:8000`.
